# Weather App

A weather application built using HTML, CSS, and JavaScript as part of a 15-day mini project challenge.  
The app fetches real-time weather data using the free OpenWeatherMap API.

## Features
- Search weather by city name
- Displays temperature, weather condition, humidity, and wind speed
- Real-time data fetched from OpenWeatherMap API
- Clean and responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript
- OpenWeatherMap API (Free)
